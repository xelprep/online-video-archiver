Anti-detection & rate limiting

Makes downloads look like a normal human browser: a consistent identity, human-like pauses between downloads, and a response when YouTube rate-limits us. TLS impersonation (recommended) makes the TLS handshake match a real browser; when it's off, the fixed User-Agent below is sent instead.

Fractional seconds are allowed (e.g. 0.5 = 500 ms) for finer-grained, less predictable pauses.

Proxy rotation (SOCKS5)

When YouTube rate-limits your IP, the archiver can route downloads through a vetted public SOCKS5 proxy and rotate when one stops working. The pool is built only when needed (reactively) and the archiver probes your direct connection periodically, dropping back to it once you're no longer throttled. Off by default.

Error email (SMTP)

When the archiver hits an error it can email you, so failures are visible even when running unattended. For Gmail: create an App Password (Google Account → Security → 2-Step Verification → App passwords), then use host smtp.gmail.com, port 587, encryption STARTTLS.

Email last-run summary Sends a short summary (which channels got new videos and how many) to the To address after each scheduled cycle. Needs SMTP configured.
